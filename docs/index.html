Eris — Interfaz moderna, ahora con voz

Controla la interfaz con voz, reproduce texto y transcribe tu voz en tiempo real. Compatible con navegadores modernos (Chrome/Edge recomendados para STT).

Abrir demo de voz Ver características

Características

  • Text-to-Speech (TTS)

    Reproduce texto con selección de voz, ajustes de velocidad y pitch.

  • Speech-to-Text (STT)

    Transcribe voz en tiempo real con resultados intermedios y finales.

  • Grabación y descarga

    Graba desde el micrófono y descarga el audio en WAV.

  • Bilingüe

    Interfaz en Español e Inglés con selector rápido.

Cómo probar

  1. Abrir "Abrir demo de voz" (se abrirá la página de demo en otra pestaña).
  2. Permitir acceso al micrófono cuando el navegador lo solicite.
  3. Usar Chrome o Edge para mejor compatibilidad STT.
